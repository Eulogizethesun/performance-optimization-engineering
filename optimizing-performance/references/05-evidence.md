# 证据：用最小代价确认候选

发现靠推理，确认才测量。目标是用最少测量排除最多错误候选，不是把系统测个遍。

---

## 四级证据

| 级别 | 手段 | 能证明 | 不能证明 |
|---|---|---|---|
| **E0 静态 + 成本模型** | 读代码、数次数、估量级 | 值不值得查、上界 | 真实收益 |
| **E1 计数/剖析/轨迹** | 计数器、profiler、trace、日志 | 工作量存在、频次、占比 | 因果、端到端收益 |
| **E2 差分** | 开关、版本、配置、副本对比 | 因果与量级 | 长期正确性 |
| **E3 正确性与回归** | 测试、长跑、故障注入、灰度 | 可以安全上线 | 更大范围收益 |

排序用 E0；确认工作量用 E1；确认"改了会快"用 E2；确认"能上线"用 E3。**没有 3–5 个候选之前，不要搭测量台。**

---

## E0 静态推理

1. 每操作/每天发生多少次？
2. 每秒/每天多少操作？
3. 单次成本数量级？
4. 结果给谁用？不用会怎样？

`次数 × 频次 × 单次成本` 就是上界；小于可感知阈值或噪声，直接降级。

---

## E1 确认工作量

手段：计数器、trace/span、profiler、系统调用统计、队列/缓存状态。具体采集、聚合、读法与常见错误见 `05a-stage-and-profile.md`。

产出：`工作项 → 次数 → 占比`，足以挑出值得进 E2 的候选。

---

## E2 差分

1. 只改一个变量。
2. 同窗交替，或至少交替两个窗口。
3. 看差值是否大于波动、方向是否稳定。
4. 同时看主指标与护栏。

不要：先跑完 A 再跑 B；同时改多个变量；只跑一次；问题在尾部却只看平均；把"重试后成功"算进正常时延。

---

## E3 上线前最小验证

- 不变量：结果、顺序、一致性、幂等、生命周期。
- 失败路径：依赖超时、队列满、缓存失效、部分失败。
- 兼容：旧数据/旧版本/旧配置。
- 护栏：错误率、资源峰值、相邻操作不变慢。
- 回滚：能一键退回，且回滚经过验证。

---

## 测量陷阱

| 陷阱 | 对策 |
|---|---|
| 观测开销改变被测对象 | 同版本开/关对比 |
| 采样偏差 | 计数 + trace 交叉 |
| 计数器当收益 | 端到端单独测 |
| 组件当端到端 | 先算占比 |
| 热函数当瓶颈 | 看工作量能否减少 |
| 缓存热当算法好 | 冷/热分开 |
| 合成负载当真实 | 真实样本或回放 |
| 单次观测当规律 | 两个窗口/机器 |
| 相关当因果 | 差分或找机制 |
| 分母错 | 先定义分子/分母 |

---

## 证据够不够

| 决策 | 最低证据 |
|---|---|
| 进候选表 | E0 |
| 认为工作确实存在 | E1 |
| 认为改它会有收益 | E2 + 量级 |
| 认为可以上线 | E3 + 护栏 + 回滚 |
| 对外宣称收益 | E2 + 端到端 + 样本量 + 可复现窗口 |
